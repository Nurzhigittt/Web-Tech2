Assignment #2 — Advanced CSS: Flexbox & Grid




Student: Nurzhigit Duiset




Group: IT-2501







This project demonstrates Flexbox and CSS Grid layouts. All tasks were completed without floats or external frameworks.
Task 0 — Navigation Bar
A navigation bar was created with a logo on the left and navigation links on the right. Flexbox aligns the elements horizontally and vertically, while gap adds equal spacing between links.

Task 2 — Page Layout with Grid Areas



A page layout was created using CSS Grid. It contains a header at the top, a sidebar on the left, main content on the right, and a footer at the bottom. Grid areas define the position of every section.

The card row, gallery, and portfolio are now inside the main content of this one page.

An image gallery with nine images was created using CSS Grid. The gallery has three equal columns and three rows with consistent gaps. A caption appears when the cursor is placed over an image.

Work Process Summary
First, I created a Flexbox navigation bar and a row of cards. Then I used CSS Grid to create a page layout and an image gallery. Finally, I combined both layout methods in a portfolio page. During this work, I used properties such as display: flex, justify-content, align-items, gap, display: grid, grid-template-columns, grid-template-rows, and grid-template-areas
